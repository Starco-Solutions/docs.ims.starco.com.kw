System

System contains IMS user/security administration, settings, workstation authorization, diagnostics and update functions. IMS 9.4.4 uses the global user identity model while keeping operational permissions and data scope company-specific.

System menu

ModuleScope

OptionsUser/application options and preferences.
Users AccountsMaintain IMS user accounts.
Group PoliciesMaintain role/group permissions and access rules.
Users ActivityReview recorded IMS user activity.
SettingsMaintain system-level IMS configuration.
Workstation AdminUse the separate IMS Global → Workstations screen for central authorization.
System DashboardView application/database/HA health, sessions, workstations and recorded transaction performance.
Check for updatesCheck the IMS client for an available application update.
