Change Password

Change Password lets the currently signed-in IMS user replace their own password. IMS first asks the user to confirm the existing password, then opens the password-change dialog where the new password is entered twice.

Open the screenSystem → Change Password.

1. Confirm the current password

IMS first displays Enter your current password. The password entry is masked. The OK button remains disabled until something has been entered.

When OK is clicked, IMS verifies the entered password through IMS Security Guard for the currently active IMS user. If the password matches, the confirmation succeeds and IMS continues to the password-change dialog. If it does not match, IMS reports that the password is incorrect, clears the entry and returns focus to the password box.

Forgotten passwordIf the current password cannot be confirmed, the screen instructs the user to contact the System Administrator rather than bypassing the current-password check.

2. Enter the replacement password

After the current password has been confirmed, the Change Password dialog asks for:

FieldPurpose
Enter PasswordThe new password the user wants to use for IMS.
Retype PasswordConfirmation of the same replacement password before Save.

Enter matching passwords of at least eight characters. Click Save to submit the new password, or Cancel to leave without completing the change.

Recommended workflow

  1. Open System → Change Password.
  2. Enter the current IMS password and click OK.
  3. Enter the new password.
  4. Retype the same new password in the confirmation field.
  5. Click Save.
User account securityChange Password operates on the currently signed-in IMS account. It is separate from administrative account maintenance under System → Users Accounts.
