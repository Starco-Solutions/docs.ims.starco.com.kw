System Dashboard

System Dashboard is a read-only operational view of the IMS client, PostgreSQL server, active connections, recent workstations, access information and recorded transaction performance.

Open the screenSystem → System Dashboard. The menu requires the manage system settings permission.

Application Version

FieldMeaning
Latest VersionThe latest IMS application version recorded in IMS Global.
Current VersionThe version of the IMS executable currently running on this workstation.
Latest UpdaterThe latest updater/loader version recorded in IMS Global.
Current UpdaterThe file version of the local Update.exe.

Server Info

Server Info identifies the database environment used by the current IMS session.

FieldMeaning
Database NameThe active IMS database.
Server AddressThe database-server address used by the active connection.
Database EngineThe configured database engine; IMS identifies PostgreSQL when no more specific engine description is supplied.
Server's RegionThe configured IMS/database time zone.
Server's Date/TimeThe current server-side date and time known to IMS.

High Availability monitoring

For cluster monitoring, an administrator uses IMS Global → System → HA Health. See IMS Global administration. The Client System Dashboard presents workstation and company-connection diagnostics.

Connection Statistics

MetricMeaning
Connection LatencyThe query-response timing measured by IMS when the dashboard opens.
Active ConnectionsSummary of active IMS-related clients and their PostgreSQL connections.
Active WorkstationsDistinct workstation PCs recorded in the Access Log during the last 10 days.

Workstation Info

This section identifies the computer on which the dashboard is currently open: PC Name, Local IP Address, Public IP Address and the workstation's current date/time.

Access Log

The upper Access Log grid shows recent workstation/client information recorded by IMS:

ColumnMeaning
PC NameRecorded workstation name.
Local IP / Public IPRecorded network addresses for the workstation.
DB ServerDatabase server recorded for that workstation/session.
IMS Version / IMS DateApplication version and corresponding IMS build/date information recorded in the access entry.
Loader VersionUpdater/loader version recorded for the workstation.
Last Run / Last ActivityMost recent run and activity timestamps recorded in the Access Log.
Current UserThe most recently recorded IMS user for the workstation.

Database Sessions

The lower grid summarizes live PostgreSQL sessions for the active IMS database, grouped by:

  • Database
  • Application Name
  • User Name
  • Client Address
  • Sessions

The status line at the bottom combines the recent-workstation count with the current total PostgreSQL session count for the active database.

Performance Monitor

The transaction Performance Monitor summarizes recorded operations in System Dashboard. It summarizes recorded transaction timings over a selected date range so administrators can compare Store/workstation performance without reading raw timing rows.

The default range is the last seven days through today. Choose From and To, optionally enable Trans. Type, then click Filter.

ColumnMeaning
Store NameStore associated with the recorded transaction.
PC NameWorkstation that recorded the timing; blank workstation names are shown as Unknown.
TransactionShown only when Trans. Type is enabled. IMS uses the transaction-code description, or the code number when no description is available.
Min / Max / Avg.Minimum, maximum and rounded average recorded transaction time in milliseconds for that group.
HealthClassification based on the average: Good ≤ 1,000 ms; Fair ≤ 2,000 ms; Slow ≤ 4,000 ms; Critical > 4,000 ms.
Diagnostic dataThe grid reports timing rows already recorded by IMS. A Store/date range with no recorded performance data returns no rows; System Dashboard does not generate historical timings retroactively. Transaction timing is recorded when debugging is enabled for the Store; this view does not enable it.
Operational useThe dashboard is useful when checking whether clients are on the expected IMS version, confirming which database/server is active, inspecting current sessions and comparing recorded transaction timing by Store/workstation.
