Workstation Admin

Workstation Admin controls which registered computers are authorized to run IMS and whether newly detected workstations are approved automatically or require administrator approval.

Open the screenSystem → Workstation Admin.

Workstation list

The screen displays the registered IMS workstation records in a read-only grid. Unauthorized workstations are listed before authorized ones, with the most recently seen workstations prioritized within the list.

ColumnMeaning
Workstation IDThe IMS workstation identity used by the authorization system.
Workstation NameThe friendly workstation name recorded by IMS.
Machine NameThe Windows computer name.
Windows UserThe Windows account recorded for the workstation.
Store IDThe Store associated with the workstation when recorded.
AuthorizedShows whether the workstation is currently approved to use IMS.
First Seen / Last SeenWhen IMS first and most recently detected the workstation.
Hardware FingerprintThe hardware-based workstation fingerprint used by the IMS authorization mechanism.
NotesAdministrative notes stored with the workstation record.

Administrative actions

ActionBehavior
RefreshReloads the workstation list and the current Auto Approve state.
ApproveAuthorizes the selected workstation. IMS reloads the list after the change.
BlockBlocks the selected workstation after an administrator confirmation.
Enable / Disable Auto ApproveControls whether new workstations are approved silently or must be approved manually by an administrator.

Auto Approve

The status line clearly shows one of two operating states:

  • Auto Approve: ENABLED — new workstations are approved silently.
  • Auto Approve: DISABLED — new workstations require administrator approval.

Changing the Auto Approve state requires confirmation. When Auto Approve is disabled, a newly detected workstation cannot be used normally until an administrator selects it and approves it.

Recommended controlFor a controlled production environment, keep Auto Approve disabled after deployment or rollout work is complete, then approve new or replaced workstations deliberately.

Approve a workstation

  1. Open System → Workstation Admin.
  2. Click Refresh if the workstation was just registered.
  3. Select the required workstation row.
  4. Review its Machine Name, Windows User, Store, First/Last Seen and Hardware Fingerprint.
  5. Click Approve.
  6. IMS reloads the list and confirms that the workstation was approved.

Block a workstation

Select the workstation and click Block. IMS asks for confirmation before changing the workstation authorization state.
