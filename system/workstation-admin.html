Workstation Admin

Use IMS Global → Workstations to review and authorize central workstation records through IMS.Api.

Current administration routeThe reviewed IMS client 9.4.4 menu does not contain the older company-local Workstation Admin screen. The current procedure below is verified against IMS Global 1.4.0 source.

Workstation list

The Global screen shows workstation identity, friendly name, machine name, authorization, first/last seen, fingerprint-change time, hardware fingerprint and notes. Timestamps are presented in workstation-local time.

Administrative actions

Refresh reloads the records. Approve authorizes the selected workstation; Block changes its authorization after confirmation. The workstation running IMS Global cannot block itself.

Earlier screen instructions

The current Global screen does not expose the older Auto Approve toggle, Windows User column or Store ID column. Do not use earlier company-local instructions as a guide to this screen.

Approve a workstation

  1. Open IMS Global → Workstations using an authorized Global Administrator account.
  2. Refresh and select the intended record.
  3. Check identity, friendly name, machine, first/last seen and fingerprint details against the workstation being authorized.
  4. Click Approve and review the refreshed authorization state.

Block a workstation

Select the intended record, click Block and review the confirmation. The self-block safeguard applies to the current workstation.

See IMS Global workstation administration and source baseline. Source verification does not establish the deployed version or hardware spoof resistance.
