Options

Options controls local IMS appearance preferences and the default Windows printer/copy settings used by common transaction and report groups on the current workstation.

Open the screenSystem → Options.

Appearance

SettingPurpose
ThemeSelect the IMS appearance. The current client provides Default, Light and Dark theme choices.
LanguageSelect the installed IMS user-interface language.

IMS applies the saved local Theme and Language selection when the application starts. If either setting is changed, Save asks whether IMS should restart immediately so the new appearance/language can be applied.

Restart is optional at Save timeIf Theme or Language changes, IMS offers to restart automatically. Choosing No saves the new setting without immediately restarting the client.

Printing Defaults

Options stores separate default printer settings for four print groups:

Print groupUsed for
Sales TransactionsThe default printer and copy count for sales-transaction printing.
Stock TransfersThe default printer and copy count for Stock Transfer printing.
Daily Cash ReportThe default printer and copy count for the Daily Cash Report.
Other ReportsThe default printer and copy count for report printing that uses the general report-printing preference.

The printer-name and Copies boxes are read-only in the Options screen. Use Change beside the required print group to open the standard Windows Print dialog.

Change a default printer

  1. Click Change beside the required print group.
  2. Select a Windows printer in the Print dialog.
  3. Select the required number of copies in that dialog.
  4. Return to Options and verify the selected printer and Copies value.
  5. Click Save.

IMS records the printer name and copy count returned by the Windows Print dialog separately for each of the four print groups.

Save local options

Click Save to store the current Theme, Language and printing defaults. IMS writes the settings to its local login/options data and records a Changed Local Options activity-log entry.

These settings are local client preferences rather than global company configuration, which allows different IMS workstations to use different printers and appearance settings where needed.
