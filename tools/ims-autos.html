IMS Autos

IMS Autos is the administration screen for the IMS background automation service. It defines the daily maintenance time and selects which scheduled maintenance jobs the server service should run automatically.

Open the screenTools → IMS Autos.

Configuration screen and server service

The IMS client screen does not perform the scheduled jobs itself. It saves the automation schedule and enabled options in the IMS database. The IMS Autos Windows service running on the server reads those settings and executes the background work.

This separation allows an administrator to configure automation from the normal IMS client while the server continues to execute the jobs even when that user's workstation is closed.

Run every day at

Select the daily maintenance time, then enable the required jobs. The server worker checks the IMS automation configuration regularly and starts the daily shift when the configured hour and minute are reached.

Daily maintenance shiftDuring the scheduled maintenance shift IMS sets the Autos maintenance state so normal transaction processing can be blocked while the selected maintenance jobs are running. Choose a low-activity time appropriate for the business.

Scheduled daily jobs

OptionWhat the server does
Apply Sale SeasonsProcesses Sale Season start/end rules. Newly starting seasons apply their configured sale prices; ended seasons either return eligible items to original price or leave them in the applicable post-sale/outlet state according to the Sale Season policy.
Stock MaintenancePerforms the full all-store stock reconstruction used by Stock Maintenance: opening quantity plus purchases/returns, transfer in/out, sales/returns, adjustments and depreciation.
Save Daily Stock LevelsMaintains the daily stock-movement history used by historical stock/reporting logic. The current service recalculates recent dates and catches up from the latest logged movement date when necessary.
Refresh Sell Through Materialized ViewRefreshes the Sell Through materialized view so Sell Through reporting uses the latest prepared inventory/sales aggregates.
Call Customized Integrations ProcessesControls the existing V-Count integration schedule in the current server service, including configured sales/traffic exchange. Integration Center MORNING_SHIFT endpoints are handled separately after the daily maintenance shift.
Integration Center in IMS 9.4.4After the scheduled daily maintenance shift completes and normal transactions are re-enabled, IMS Autos runs active Integration Center endpoints whose Trigger Type is MORNING_SHIFT. This execution is separate from the Call Customized Integrations Processes checkbox used by the V-Count schedule.

Daily stock movement maintenance

The option shown as Save Daily Stock Levels maintains IMS daily stock-movement data rather than simply saving one static quantity snapshot. For each recalculated date, the service rebuilds daily movement from:

SourceMovement treatment
Purchases / Purchase ReturnsPurchases add stock; Purchase Returns subtract it.
Stock TransfersTransfer In adds stock to the destination; Transfer Out subtracts from the source.
Cash / Credit Sales and ReturnsSales subtract inventory quantity; returns add it back.
Stock AdjustmentsUses the signed adjustment quantity.
Stock DepreciationSubtracts depreciated/write-off quantity.

Normally the service recalculates the most recent five days through today. If the movement log shows that an older date was missed, the service expands the range to catch up from the first missing day.

Loyalty housekeeping during the daily shift

The server worker also performs required Loyalty/Star Rewards housekeeping as part of the daily automation shift when the corresponding loyalty settings are in use. This includes processing eligible pending reward activity after the configured return period and maintaining applicable loyalty state.

This housekeeping is part of the server-side automation workflow rather than a separate checkbox on the IMS Autos screen.

Other background work handled by IMS Autos

The Autos service is more than the five daily checkboxes. The current server worker also performs background jobs that have their own schedules or triggers:

Background functionPurpose
Reporting Scheduler tasksChecks active scheduled Custom Report tasks, generates the required period, writes TXT/CSV/XLSX output and sends it through the configured Email and/or FTP destination.
Online-order supplier notificationsEvery recurring Autos check looks for online orders created after the last processed order time for each configured Profile/Store, groups their inventory items by Supplier/Brand, and sends the order request to the applicable Supplier Mailing List recipients.
Integration Center MORNING_SHIFTAfter the daily maintenance shift, runs active Integration Center endpoints configured for MORNING_SHIFT and records their result in the Integration Center Sync Log.
V-Count integrationWhen configured, exchanges hourly sales/category information and imports recent people-traffic data during the configured V-Count operating hours.
Star Rewards automationPerforms recurring Loyalty/Star Rewards maintenance such as applicable expiry and automated loyalty-offer processing.
Reporting SchedulerThe report schedule itself is defined under Tools → Reporting Scheduler. IMS Autos is the server worker that checks those active tasks and executes them at the required time.

Online-order supplier notifications

This workflow is independent from the daily Autos schedule. The Autos service performs its general check approximately every 30 seconds, and CheckNewOrders runs whenever the IMS database connection is available.

  1. For each configured online Profile/Store, IMS Autos reads the last processed order date.
  2. It finds newer records already created in IMS Orders.
  3. It loads the inventory-item lines from Order Details and groups them by Supplier + Brand.
  4. Recipients are selected from the Supplier Mailing List: global recipients, supplier-wide/all-brand recipients, and exact supplier/brand recipients.
  5. Autos sends an HTML “new transfer request” email containing Order No., Barcode, Description, SKU/Style, Color, Size and Qty.
  6. After processing the batch, Autos advances the last processed order date for that Profile/Store.
JIT workflow timingFor a JIT online order, the supplier notification happens after the Shopify service has inserted the order into IMS — before the later JIT purchasing transaction created when Incoming Orders is invoiced.

Save the Autos schedule

  1. Select the daily Run every day at time.
  2. Enable the required daily jobs.
  3. Click Save.
  4. IMS stores the schedule and writes a “Modified IMS Autos settings” entry to the activity log.

If all daily-job checkboxes are cleared and the settings are saved, IMS removes the daily Autos schedule record rather than keeping an empty daily shift.

Service monitoring and logs

The server service writes informational, success-audit and error messages to the Windows Event Log for its major jobs and connection failures. Administrators can use these logs to confirm when the daily shift started, which jobs completed, and whether a background integration or maintenance task reported an error.
