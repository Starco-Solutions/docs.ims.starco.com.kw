Label Printing

Label Printing prepares item labels in bulk and previews them before printing. Labels can be built from an Item Code or Barcode, an entire Style, the Style/Color identified by a scanned barcode, an imported list, or the positive stock balance of a selected store.

Open the screenTools → Label Printing.

Choose Price Label or Sale Label

Label typeBehavior
Price LabelUses the installed LBL_ label layouts. The user can choose Original Price or Current Price and English or Arabic description.
Sale LabelUses the installed LBLS_ sale-label layouts. Price and description selectors are disabled because the selected sale-label report controls its own layout/content.

The Report list is populated from the label report layouts installed with IMS. Click Preview >> after items have been prepared to render the selected layout in the preview pane.

Add items to the label list

There are several ways to build the label list.

Item / Barcode

Select Item/Barcode, enter the quantity, then scan or type an Item Code, the item's primary barcode or an alternate barcode. IMS loads the matching item and displays Brand, Style, Description, Color, Size, Original Price and Current Price.

Style

Select Style when the entered value is a Style rather than an individual item. IMS loads the item variants belonging to that Style, with the entered Qty applied to each newly added item.

Get scanned style

Enable Get scanned style when the scanned value is a barcode but the objective is to label the complete Style. IMS first identifies the Style represented by that barcode and then loads all items in the Style.

While Get scanned style is enabled, Get scanned color becomes available. Enable it to restrict the result to the scanned item's Style + Color combination instead of every color in the Style.

Duplicate itemsIf an Item Code is already in the label list and store-balance mode is not active, scanning/adding it again increases its label Qty instead of creating another duplicate row.

Generate labels from a store's stock balance

Enable Get store's balance and select a Store when the number of labels should match the current positive on-hand quantity in that location.

In this mode the manual Qty field is disabled. For every matched item IMS reads the selected store's stock balance, uses that positive balance as the label quantity, and skips items whose store balance is zero or negative.

This can be combined with Style/scanned-Style selection to prepare labels only for variants that are actually available in the selected store.

Price and description options

For Price Labels, choose the information required by the selected template:

OptionResult
Original PriceThe label report is told to use the item's original price.
Current PriceThe label report is told to use the current selling price.
En-Desc.The label report is told to use the English description.
Ar-Desc.The label report is told to use the Arabic description.

Import a label list

Import reads a tab-delimited text file with a header row. Label Printing supports three practical layouts:

LayoutExample
Item Code + QtyProdn[TAB]Qty
Style + QtyStyle[TAB]Qty
Style + Color + QtyStyle[TAB]Color[TAB]Qty

Qty must be a whole number. Item Code values are limited to the supported IMS Item Code length, while Style/Color values are validated against their supported text length. If validation errors are found, IMS writes a -ValidationLog.txt file beside the imported text file with the row number and error message.

Preview and print

  1. Build the label list manually or through Import/store balance.
  2. Select Price Label or Sale Label.
  3. Select the installed Report layout.
  4. For Price Labels, choose Original/Current Price and English/Arabic description.
  5. Click Preview >>.
  6. Review the Crystal Reports preview on the right.
  7. Use the Crystal Reports viewer's print controls to send the labels to the configured printer.

IMS prepares one printable label instance for each unit of Qty. For example, an item with Qty 12 contributes twelve labels to the preview.

Clear the working list

Click Clear to remove the current item rows and reset the preview. Closing the Label Printing screen also clears the temporary label-printing records created for that workstation/session.

Common workflows

RequirementRecommended setup
Print one or several labels for one SKUItem/Barcode → enter Qty → scan/type item → Add.
Print the same Qty for every variant in a StyleStyle → enter Style and Qty → Add.
Scan one item and label every variant of its StyleEnable Get scanned style → scan barcode → Add.
Scan one item and label only the same Style/Color variantsEnable Get scanned style + Get scanned color → scan barcode → Add.
Print exactly the current positive stock in one storeEnable Get store's balance → choose Store → select/scan Style or items.
Prepare a large predefined label batchUse Import with Item/Qty, Style/Qty or Style/Color/Qty.
