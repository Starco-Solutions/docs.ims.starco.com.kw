Tools

The Tools menu contains operational utilities, maintenance functions and configurable reporting tools that support day-to-day IMS work outside the main Sales, Inventory, Financial, Reports and Manage workflows.

ModuleScope

Stock MaintenanceStock-maintenance utilities.
IMS AutosIMS automation/service tools.
Custom ViewsCustom view definitions used by IMS.
Custom ReportsCustom report definitions that can be exposed through User-Defined Reports.
Reporting SchedulerScheduled report generation and configured delivery destinations.
Custom AttributesCustom attribute definitions used by supported IMS master-data areas.
