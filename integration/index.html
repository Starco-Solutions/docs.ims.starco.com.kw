Integration

The Integration area contains IMS workflows that exchange operational data with specialized external systems. It includes Starco Stock Take, V-Count Settings and Integration Center.

Menu locationIntegration is a top-level IMS menu. Integration Center is opened from Integration → Integration Center; it is not part of Tools.

Integration menu

ModuleScope
Starco Stock TakeExports Store inventory data in the formats required by the handheld stock-taking application, with optional Supplier filtering.
V-Count SettingsMaintains V-Count connection settings used by IMS automation to collect Store traffic data for reporting and conversion analysis.
Integration CenterCreates and maintains configurable outbound integration endpoints, previews their source views, monitors current health and reviews detailed synchronization logs.

How the three workflows differ

Starco Stock Take is a purpose-built outbound export for handheld physical stock taking.

V-Count is a purpose-built traffic integration whose connection settings are consumed by the background automation process.

Integration Center is the configurable integration framework for IMS. Each integration defines its source view, endpoint, authentication, trigger and JSON payload settings. IMS Autos executes active MORNING_SHIFT endpoints after the daily maintenance shift and writes each request result to the Sync Log; MANUAL remains a supported trigger classification without an Integration Center Run button in IMS 9.4.5.

AccessThe Integration top-level menu is controlled by the Integrated Reports permission in Group Policies. If the whole Integration menu is missing, review the user's policy.
