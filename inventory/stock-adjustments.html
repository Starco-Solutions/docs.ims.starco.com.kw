Stock Adjustments

Stock Adjustments corrects a store's inventory balance when the system quantity must be increased or decreased to match an approved physical or operational correction. Adjustment quantities are signed: a positive quantity adds stock and a negative quantity removes stock. IMS records the item's current retail and cost values, updates the store balance, keeps a transaction log, and supports financial posting for negative stock discrepancies.

Open the screenInventory → Stock Adjustments.
Current financial integration The current IMS deployment posts eligible Stock Adjustment discrepancy journals directly to the local Al-Shamel Financial Management System. This guide uses the generic business term Financial Posting so the stock-adjustment workflow remains valid when another financial connector is introduced later.

When to use Stock Adjustments

Use Stock Adjustments when an approved correction must change the on-hand quantity without creating a Purchase, Stock Transfer or Stock Depreciation voucher. Typical examples include correcting a stock-count difference or fixing an inventory quantity that is known to be inaccurate.

Adjustment QtyEffect on store stock
PositiveAdds the entered quantity to the store's on-hand balance.
NegativeSubtracts the absolute quantity from the store's on-hand balance and represents a stock shortage/discrepancy.

Select the store

Select the Branch/Store whose stock is being corrected. IMS loads that location's existing adjustment vouchers and the financial information associated with the store.

Use the First, Previous, Next and Last controls to browse vouchers. The Voucher No. field can also be used to jump directly to a known voucher.

Create a new adjustment voucher

  1. Select the required store.
  2. Click New.
  3. Enter a clear reason in Notes.
  4. Enter the required signed Qty and scan/type the item, or use Import for a prepared list.
  5. Review Item Code, Retail Price, Item Cost and Total Cost.
  6. Review Total Qty, Total Retail and Total Cost for the voucher.
  7. Click Save.

A voucher must contain at least one item. IMS also respects the inventory maintenance/processing controls before allowing the transaction to proceed.

Add items manually

The item field accepts an IMS Item Code, the item's main Barcode, or an alternate barcode. IMS loads the item's Description, Style, Color, Size, Unit, current Retail Price and current Cost.

The Qty field accepts whole numbers and can be positive or negative. The resulting signed quantity is used in all voucher totals.

Import adjustment items

Use Import for a larger stock correction. The file is a tab-delimited text file with a header row and the following columns:

Import format 
ItemCode	Unit	Qty
30225010001	1	3
30225010002	1	-2

The Qty column is a signed whole number, so the same file can contain both increases and decreases. IMS validates the Item Code, Unit and Qty format, and rejects duplicate Item Code rows.

If validation fails, IMS creates an -ErrorLog.txt file beside the import file containing the row number and reason. Retail and Cost values are taken from the IMS item master and do not need to be supplied in the file.

How the adjustment changes stock

When a new voucher is saved, IMS adds each signed adjustment quantity to the selected store's current on-hand balance. Therefore a +5 adjustment increases stock by five units and a -5 adjustment reduces stock by five units.

IMS Client 9.4.5: When saving a new adjustment or editing an existing one, IMS creates any missing store/item balance records before applying the revised adjustment quantities. Each missing balance starts at zero. Existing balance records are retained, and repeated Item Codes do not create duplicate balance records.

Affected items are also queued for the normal IMS online-item update process so connected online inventory processes can react to the change.

Edit an unposted adjustment

An authorized user can edit an existing voucher while it has not been financially posted. IMS first reverses the effect of the original adjustment, replaces the voucher details, and then applies the revised signed quantities.

The resulting balance reflects the revised quantities after the edit completes successfully.

Developer notes: missing stock-balance records

In IMS Client 9.4.5, both SaveNew and UpdateVoucher call EnsureItemProdsRecords after writing the new voucher details and before applying the signed stock update. The helper collects distinct Item Codes from the detail grid and submits one parameterized bulk insert into item_prods, using paired text[] product and numeric[] cost arrays.

For a missing row, the insert uses the selected store, the first encountered cost for that Item Code, zero quantity and the supplier from the matching items.vendor. ON CONFLICT (prods, prodn) DO NOTHING preserves existing store/item rows and their values. The subsequent stock update sums the voucher lines by store and Item Code before applying the signed quantity. Deduplication here affects only balance-row creation; repeated detail quantities still contribute to the adjustment total.

Void an adjustment

An unposted voucher can be voided after confirmation. IMS reverses its stock effect, removes the item detail rows and sets the voucher totals to zero.

The deleted quantity/cost information is retained in the Notes together with the previous notes, and the action is written to the transaction log.

Posted vouchersA Stock Adjustment cannot be edited or voided while it has a financial journal attached. Unpost the journal first when correction is authorized.

Financial Posting — negative discrepancies

The current financial-posting workflow is intended for negative stock discrepancies. IMS only offers the Stock Discrepancy journal when the voucher's Total Cost is negative and the financial integration/store setup is complete.

The journal balances the store's Inventory Account against the configured Discrepancies Account, using the selected store's accounting branch and cost center. In the current deployment, the journal is written directly to Al-Shamel.

After a successful post, IMS stores the Journal No., posting user and posting date/time on the adjustment voucher and records the event in the transaction log.

Positive adjustments A positive-cost adjustment changes the IMS inventory balance but is not posted through this Stock Discrepancy posting action. If a positive correction requires an accounting entry, follow the company's approved financial procedure.

Unpost a discrepancy journal

For a voucher posted through IMS, the action changes to UnPost. After confirmation, IMS removes the related Al-Shamel journal, clears the posting information from the Stock Adjustment voucher, and records the unpost action in the transaction log.

A voucher marked as manually posted is shown as such and is not available for normal IMS posting from this screen.

Transaction log

The Log panel shows the date/time, IMS user and action recorded against the selected voucher. Typical entries include adding, editing, voiding, posting and unposting the adjustment.

Permissions

New, Edit and Void are controlled by the Stock Adjustment management permission. Financial posting is controlled separately by the Financial Posting permission.
