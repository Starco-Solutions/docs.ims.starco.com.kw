Stock Level

Stock Level is the main inventory-balance analysis screen in IMS. It can report the current stock or reconstruct the quantity at an earlier date, filter the inventory by store and product attributes, group the result from high-level summaries down to Item Code, and calculate quantity, inventory cost and retail value.

Open the screenInventory → Stock Level.

Current stock or stock as of an earlier date

Use the As In date to choose the inventory date. When today's date is selected, IMS reads the current stock balance. When an earlier date is selected, the screen changes to a historical balance view and displays Balance until [date].

The historical quantity is reconstructed from the item's opening/first quantity plus the recorded daily inventory movements up to the selected date. This makes Stock Level useful for answering questions such as “What quantity did we have at the end of last month?” without changing the current inventory.

Historical-stock noteThe selected date controls the stock quantity being analyzed. Product master information such as descriptions, classifications and current price fields still comes from the item master used by the report.

Filter the inventory

The criteria are split across Main, Categories and Items Info areas. Multiple values can be selected for most master-data criteria.

CriteriaWhat it filters

BrandsAvailable when the selected supplier scope allows a brand selection.
Age Range / GenderItem demographic classifications.

Using IMS multi-selection fields

Stock Level uses the shared IMS multi-selection list for Stores, Suppliers, Brands, Age Ranges, Genders, Seasons and the category hierarchy. You can select several values without holding Ctrl.

  1. Click the criteria field to open the list.
  2. Click each required value to select or deselect it.
  3. Close the list, double-click an item, or click outside the popup to apply the selection.
DisplayMeaning
AllAll available values are included.
One nameExactly one value is selected.
Multi SelectedTwo or more values are selected.

Choose how Stock Level is grouped

The Group By checkboxes determine the descriptive columns and the level at which quantities and values are summarized. Available grouping dimensions include:

AreaGroup By options
Organization / supplierStore, Supplier, Brand
Customer/product classificationAge Range, Gender, Category, Sub Category, Group, Sub Group
SeasonReceived Season, Statistical Period
ProductStyle, Description, Theme, Color, Size
Full item detailItems Details adds Item Code, Barcode, Original Price, Current Price, discount %, last-purchase currency/price, item State and last received date.

Available colors and sizes

When the report is grouped by Style without drilling all the way to Size or Item Details, IMS adds availability indicators that compare variants currently in stock with the variants defined for the Style. At Style level it can show Available Colors / Total Colors and Available Sizes / Total Sizes. When Style + Color is selected, it can show the available/total Size count for that color.

Stock measures

Every generated Stock Level result includes the core inventory measures below.

MeasureMeaning
QtyOn-hand quantity for the selected criteria/group.
Total CostQty × inventory unit cost, summed for the group.
Avg. Unit CostWeighted average inventory unit cost for the group.
Total RetailQty × current retail price, summed for the group.
CountNumber of result rows currently displayed.

The bottom summary shows Count, Total Qty, Total Cost and Total Retail. Cost values are hidden for users who do not have permission to view COGS/cost information.

Average retail prices

Enable Average Retail when a grouped report should also show weighted average Original Price, weighted average Current Price and the resulting discount percentage. When full Item Details are selected, the report shows the item's own price fields instead.

OH %

Enable OH % to show each result row's share of the total selected on-hand quantity. This is useful for questions such as how much of the selected inventory belongs to each Store, Brand, Category, Style or other chosen grouping.

View item images

After generating the report, enable View Image to display product thumbnails. The report must contain both Style and Color Code, because IMS uses the Style + Color combination to locate the stored thumbnail.

For very large reports IMS warns before loading thousands of thumbnails. Images are loaded in batches and the report shows progress while they are being prepared.

Generate the report

  1. Select the current or historical As In date.
  2. Select Stores and the required product/supplier criteria.
  3. Apply Qty, Original Price, Current Price and Item State filters if needed.
  4. Select the Group By dimensions.
  5. Optionally enable Average Retail or OH %.
  6. Click Generate.
  7. Review the grid and the Count/Qty/Cost/Retail totals.
  8. Optionally enable View Image, hide the criteria area, or export the result.

Export, email and Save As

Stock Level uses the standard IMS report-output workflow. Depending on user permissions, the toolbar provides Export To Excel, Send By Email and Save As.

Standard IMS report output Export requires a generated report. While IMS builds the Excel file it shows progress and temporarily disables the related report controls. Send By Email generates the report workbook as an attachment and sends it through the configured IMS email service.
Save As formats The shared Save As window can save the displayed report as Text (tab delimited), CSV or an Excel Workbook (.xlsx). It also supports removing the header when a data-only file is required.

Excel export with item images

If thumbnails are currently displayed, Excel export can include them. For reports above 5,000 rows, IMS asks whether to export with images, export data only, or cancel because image-heavy workbooks can become very large.

Send By Email exports the report data without relying on the on-screen thumbnail column.

Pricing / PDA export files

Stock Level also contains specialized pricing-file exports used by the current retail workflow.

OutputPurpose
Pricing FileExports positive-stock item information and retail pricing using the selected Stock Level criteria. For Outlet/All-state exports, IMS can ask whether original or discounted prices should be written.
Sale Pricing FileExports discounted items where Current Price is below Original Price. IMS asks for confirmation when the criteria include Outlet items or all discounted items.

These exports require a Stock Level report to have been generated first and then ask the user to choose the destination folder.

Show / Hide Filters

Use Hide Filters when the criteria are no longer needed on screen. IMS expands the report grid into the freed space. Click Show Filters to restore the criteria area.
