Star Rewards History

Star Rewards History is the loyalty-account enquiry screen in IMS. It lets an authorized user find a client, review the client's account and profile information, see the current tier, reward points and wallet value, and inspect the complete Star Rewards transaction history.

Open the reportReports → Star Rewards History

Rewards History screen

Find a client

  1. Choose whether to keep Exclude Empty Wallets selected.
  2. Choose whether to keep Exclude Non Registered Clients selected.
  3. Click Find.
  4. In the Find Client window, choose ID, Full Name, or Phone No. under Search By.
  5. Type the search value. The list filters while you type.
  6. Double-click the required client.
  7. IMS closes the Find Client window and loads the selected client's profile and reward transactions into Rewards History.

Search options

OptionBehavior
Exclude Empty WalletsWhen selected, the Find Client list includes only clients whose available reward wallet value is not zero.
Exclude Non Registered ClientsWhen selected, only clients registered in Star Rewards are shown.
Both selectedOnly registered Star Rewards clients with a non-zero wallet value are shown.
Search by IDMatches one exact client ID.
Search by Full NameFinds clients whose full name contains the entered text.
Search by Phone No.Finds clients whose mobile number contains the entered digits. This is the default search method.
Find Client summaryThe bottom of the Find Client window shows how many clients are currently displayed out of the complete loyalty client list, the total number registered in Star Rewards, and the combined available wallet value of registered clients.

Account Information

After a client is selected, IMS fills the Account Information section. These fields are read-only; Star Rewards History is intended for enquiry and investigation rather than editing the client.

Star Rewards Transactions

The Transactions grid is sorted with the most recent Star Rewards transactions first. It shows where and when the transaction occurred, how many points and what amount were involved, and the status of the points.

ColumnMeaning
Store NameStore associated with the loyalty transaction.
Inv. NoInvoice or reference number associated with the transaction, when available.
Inv. Date / Inv. TimeDate and time of the Star Rewards transaction.
Trans. TypeSales Trans., Redeem Points, Send Points, or Receive Points.
PointsNumber of reward points involved in the transaction.
AmountMonetary amount associated with the transaction.
DescriptionDescription stored with the reward transaction.
Points StatusApplied when the transaction is no longer pending; otherwise Pending.
Expiry DateExpiry date of the points when one is recorded.
Using StatusFor Sales transactions, shows Available or Redeemed / Canceled. Other transaction descriptions leave this field blank.

Transaction types

Displayed typePurpose
Sales Trans.Points activity created from a sales transaction.
Redeem PointsPoints redeemed from the client's rewards balance.
Send PointsPoints transferred out from the client.
Receive PointsPoints transferred into the client.

Understanding point status

Points Status

Applied

The loyalty transaction is no longer pending and has been applied to the rewards history.

Points Status

Pending

The loyalty transaction is still marked as pending.

Using Status

Available

For a Sales transaction, the associated reward value has not been used.

Using Status

Redeemed / Canceled

For a Sales transaction, the associated reward value is marked as already used or canceled.

Export and editing

Star Rewards History is a read-only enquiry screen. It does not provide the standard Export To Excel, Send By Email or Save As toolbar used by many IMS reports, and it does not edit the client's profile or reward transactions.

Permissions

The Star Rewards History menu is permission controlled. If it is not visible in the Reports menu, the logged-in user's IMS policy does not grant access to the Star Rewards client-history function.

Common uses

Customer service

Check a customer's wallet

Find the client and review Reward Point and Wallet Amount in Account Information.

Rewards

Why are points unavailable?

Review Points Status, Expiry Date and Using Status in the transaction history.

Registration

Confirm Star Rewards enrollment

Check Registered in Star Rewards, Profile Completed and Current Tier.

Audit

Trace point movement

Use the transaction list to review sales, redemptions, points sent and points received in date/time order.
