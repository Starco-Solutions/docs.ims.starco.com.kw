Getting Started: Login & Main Screen

This page covers IMS 9.4.6 startup, global user sign-in, company selection when required, the selected-company workspace, toolbar/menu access, connection information and navigation between open IMS screens.

Two separate approvalsA workstation must be authorized to run IMS, and then a user must sign in with an authorized IMS account. Workstation authorization happens before the normal user login.

What happens when IMS starts

  1. IMS contacts the configured bootstrap API and checks the workstation. API/service failure or workstation authorization failure stops normal startup.
  2. The global login screen appears. Enter your IMS credentials. Complete a required password change and sign in again if prompted.
  3. IMS obtains your authorized companies. It selects the sole company automatically or asks you to choose when several are available.
  4. IMS opens the selected company's database. It obtains that company's bootstrap information before opening the connection.
  5. The company workspace loads. IMS applies initialization/update checks and loads the local company account and access.
Startup troubleshootingCheck the stage that failed: API availability, workstation authorization, global credentials, company membership or selected-company database reachability. A company database connection is opened after global sign-in and company selection.

Workstation authorization

IMS controls access at workstation level as well as user level. A new computer may be registered automatically. Whether it can continue immediately or must wait for approval depends on the workstation approval setting managed by IT.

SituationWhat happensWhat the user should do
New workstation, automatic approval enabledThe workstation can be registered and approved automatically.Continue to the IMS login screen.
New workstation, approval requiredThe workstation is added as pending approval and IMS does not continue to user login.Send the displayed Workstation ID and Machine Name to IT.
Registered workstation is blocked or not yet approvedIMS shows a Workstation Not Authorized warning and exits.Contact the system administrator.
Workstation hardware identity changedIMS may require IT to review and approve the workstation again.Provide the Workstation ID and Machine Name shown in the warning.
User login cannot bypass workstation approvalIf the workstation itself is not authorized, IMS stops before the normal user login. Approval must be handled by an IMS administrator.

Signing in to IMS

IMS 9.4.6 authenticates the user against the IMS Global user store before connecting to a company database. Enter the Login Name and Password, then click Login.

  1. IMS verifies the Login Name and password against the global user identity.
  2. If the account is disabled, login stops and IMS asks the user to contact the system administrator.
  3. For a new or reset account, use the temporary password supplied by your administrator. If a password change is required, complete it and sign in again.
  4. IMS loads the companies for which the user has active access.
  5. If exactly one company is available, IMS selects it automatically. If more than one is available, the Select Company / Branch window appears.
  6. After selection, IMS connects to that company's database and loads the user's company-specific Store, Supplier, Group Policy and transaction access.
Company selectionThe list displays the company's Country Code and Company Name. Select a row and click OK, or double-click the required company.
Login messagesYou do not have access to any company means the global identity is valid but has no active company access. Failed to connect to the selected company's database means authentication succeeded but the selected company database could not be opened.

Main screen after login

Quick tour

Before opening a module, these are the six parts of the IMS workspace worth recognizing.

01
Window title & build

The title bar identifies the configured company and the installed IMS build, so users and IT can immediately confirm which environment/version is running.

02
Quick-access toolbar

The most frequently used Store functions—Sales Transactions, Items Search, POS control, cash drawer and Transactions Expert—stay one click away.

03
User, Company & Store context

The active company database is selected during login; Store/POS and Active User then define the current operational context inside that company.

04
Central workspace

IMS working screens open inside the main application so several tasks can remain available and users can move between them without reopening each module.

05
Connection status

The status area shows database latency together with server date/time and timezone, making connectivity problems visible while users are working.

06
Lock control

The round power-style control locks the IMS workspace without closing the application, protecting an unattended signed-in session.

Why menus differ between usersIMS builds the toolbar and menus from the signed-in user's access policy. Individual commands—or an entire menu—can be hidden when the account does not have the required permission.

Working with multiple IMS screens

Many IMS forms open inside the central workspace. When a supported working screen is opened, IMS adds a text button for it to the lower information strip. Use those buttons to bring an open screen to the front or hide the currently active screen. Closing the form removes its button.

Practical benefitYou can keep several IMS tasks open and move between them without repeatedly reopening each form.

Locking IMS

Use the round power-style button to lock the IMS workspace when it is available. IMS hides the normal toolbar and open working screens and displays an authentication screen. This is useful when leaving a logged-in workstation unattended.

Connection status

IMS periodically checks communication with the database server and displays the result in the lower-right corner together with the server time and timezone.

StatusWhat IMS showsMeaning
NormalConnection latency in green.The connection check completed successfully.
Higher latencyThe latency indicator changes to a warning color when it exceeds 75 ms.The server is reachable, but communication is slower than the threshold used by IMS.
DisconnectedDisconnected in red.IMS could not complete its database connection check.

Main-screen notifications

The main screen performs background checks while IMS is running. New stock transfers can trigger a visible blinking notification. New online activity can cause the Shopify button to flash red. If the server connection is lost, the main notification area can also report that the server connection is down.

IMS updates

During startup and periodic background checks, IMS can detect a newer application version. A critical update must be installed before the current version can continue. A non-critical update can be announced in the IMS title bar until the user installs it.

Language and appearance

IMS supports Arabic right-to-left layout and light/dark appearance. The theme can follow Windows or use the saved IMS preference, and the selected language is applied when the main form is created.

Common questions

Why does IMS close before I can log in?

If the database is available but the workstation is not authorized, IMS stops before user login. Give the Workstation ID and Machine Name from the warning to IT so they can review the workstation.

Why does a previously working PC suddenly require workstation approval?

A changed workstation hardware identity can require a new approval when automatic workstation approval is disabled.

Why does IMS say “Incorrect User Name or Password”?

The credentials were not accepted. Re-enter the password and verify the user name. If the account is disabled, contact the system administrator.

How do I sign in with a new or reset account?

Use the temporary password provided by the administrator, change it when prompted, then sign in again.

Why does another user have a menu that I do not see?

IMS hides menu items according to user permissions. Ask your system administrator to check your assigned access if you need that function.

Why is connection latency showing a warning color?

IMS changes the latency indicator after the measured database response time exceeds 75 ms. The system may still be connected, but communication with the server is slower.

Can I keep more than one IMS screen open?

Yes. Supported screens remain inside the main workspace, and IMS adds buttons for active child screens so you can switch between them.

Why can I not close the POS?

If Sales Transactions is still running, IMS blocks the POS close action and asks you to close Sales Transactions first.
