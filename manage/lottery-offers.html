Lottery Offers

Lottery Offers defines time-limited sales lottery campaigns. Each offer has an active period, a transaction-total trigger amount, a draw date, informational text and a store scope.

Open the screenManage → Lottery Offers.

What a Lottery Offer contains

FieldPurpose
IDSystem identifier for the lottery offer.
NameDescriptive name of the lottery campaign.
StartDate on which the offer period begins.
EndDate on which the offer period ends.
Draw DateDate scheduled for the lottery draw. IMS requires this date to be after the offer End date.
If Total >The transaction-total trigger amount used by the lottery workflow. The value must be greater than zero.
InfoFree-text information associated with the lottery offer.
Select StoresDefines which stores participate in the offer.
All StoresUses all active centers available to this module instead of a manually selected list.
Trigger AmountThe maintenance screen defines the amount threshold and offer rules. The sales-side process that records lottery chances is separate from this setup screen.

Offer dates and draw date

The three dates have different jobs:

DateMeaning
StartBeginning of the qualifying campaign period.
EndEnd of the qualifying campaign period.
Draw DateThe scheduled draw date and must be later than the End date.

IMS will not save a new offer when End is before Start, when Draw Date is on or before End, or when the Trigger Amount is zero.

When editing an existing offer, setting the End date before the current server date is treated as stopping the offer and IMS asks for confirmation before saving.

Select Stores

New lottery offers start with All Stores selected. You can clear it and use the + button to choose specific stores. Use − to remove selected stores from the campaign.

If All Stores is not selected, at least one store must be assigned before IMS will save the offer.

Create a Lottery Offer

  1. Open Manage → Lottery Offers.
  2. Click New. IMS prepares a new Offer ID and changes the toolbar to Save / Cancel.
  3. Enter the lottery Name.
  4. Set the Start and End dates.
  5. Set a Draw Date after the End date.
  6. Enter the If Total > trigger amount.
  7. Enter any campaign instructions or notes in Info.
  8. Leave All Stores selected or choose the participating stores.
  9. Click Save.

Edit an existing offer

Select an offer from the list on the left and click Edit. IMS allows the Name, dates, Trigger Amount, Info and store scope to be changed. Click Cancel to discard the unsaved changes and reload the stored offer.

Delete a Lottery Offer

An unused lottery offer can be deleted after confirmation. Once IMS finds lottery chance records for the Offer ID, the offer cannot be deleted because it has already been applied to sales transactions.

Historical protectionThis keeps the lottery definition available after sales activity has created chance records against it.

How the data relates

The offer header is stored separately from its store assignments. Sales-side lottery activity is recorded separately as lottery chance records referencing the Offer ID. This is why an offer can be maintained here while the resulting customer/sales participation is preserved independently.
