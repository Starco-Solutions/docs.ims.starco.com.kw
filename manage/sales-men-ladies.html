Manage Sales Men/Ladies

Manage Sales Men/Ladies maintains the salesperson master used by IMS sales transactions and salesperson reporting. Each person has a unique ID, Arabic and English names, join date and active status, and can be assigned to one or more stores. When the organization enables cashier access, the same salesperson can also be linked to an IMS login under the predefined cashier policy.

Open the screenManage → Sales Men/Ladies

Sales Men/Ladies screen

Browse and filter Sales Men/Ladies

The upper criteria area controls which Sales Men/Ladies are shown in the list.

ControlPurpose
BranchWhen the top All Stores option is cleared, shows Sales Men/Ladies assigned to the selected branch.
All StoresWhen selected, shows the complete Sales Men/Ladies master instead of restricting the list to one branch.
Filter By: IDFinds a Sales Man/Lady by numeric ID.
Filter By: Arabic NameFinds a Sales Man/Lady by the beginning of the Arabic name.
Filter By: English NameFinds a Sales Man/Lady by the beginning of the English name.
Total ActiveShows the number of active Sales Men/Ladies compared with the total master records loaded by IMS.
Two different “All Stores” optionsThe All Stores checkbox at the top controls how the salesperson list is filtered. The All Stores checkbox inside Can Sell In controls which active stores are assigned to the selected Sales Man/Lady.

Sales Man/Lady details

FieldMeaning
IDUnique numeric Sales Man/Lady identifier. The ID is entered when creating the record and is not changed afterward.
Is ActiveControls whether the Sales Man/Lady is active. If the person also has an IMS cashier login, the linked account follows the active/disabled state.
Can Add SalesWhen enabled and the Cashier policy is configured, allows the Sales Man/Lady to have IMS system access under the predefined cashier group policy.
LoginLogin name used when Can Add Sales is enabled. IMS requires the login name to be unique.
Join DateDate the Sales Man/Lady joined the organization.
Ar NameRequired Arabic name.
En NameRequired English name displayed in the Sales Men/Ladies list and reporting.

Add a new Sales Man/Lady

  1. Click Add New.
  2. Enter a unique ID.
  3. Enter the required Ar Name and En Name.
  4. Select the Join Date and confirm Is Active.
  5. Under Can Sell In, assign the stores where the person is allowed to sell, or select the lower All Stores option to assign all active stores.
  6. If the person also needs IMS cashier access, enable Can Add Sales and enter a unique Login name.
  7. Click Save.

IMS validates the required ID and names, prevents duplicate Sales Man/Lady IDs and validates the Login name when cashier access is enabled.

Edit an existing Sales Man/Lady

  1. Find and select the Sales Man/Lady.
  2. Click Edit.
  3. Change the required names, Join Date, active status, cashier setting or store assignments.
  4. Click Save to apply the changes, or Cancel to return to the existing values.

Can Sell In

Can Sell In defines the stores assigned to the Sales Man/Lady.

ActionBehavior
+Opens the IMS store-selection dialog so one or more stores can be added to the assignment.
-Removes the selected store or stores from the current assignment.
All StoresAssigns all currently active IMS stores to the Sales Man/Lady.

The store assignment is stored per Sales Man/Lady and is used whenever IMS needs to know which stores that person is allowed to sell in.

Can Add Sales and cashier access

When the IMS Cashier Group is configured, the Can Add Sales option is available. Enabling it connects the Sales Man/Lady master with an IMS user account so the employee can sign in and add sales under the predefined cashier group policy.

For a new cashier, IMS creates the linked user account, assigns the configured Cashier Group and synchronizes the person's store-related access from the Can Sell In assignment.

Automatic access derived from Can Sell In

For Sales Men/Ladies with cashier access, IMS uses the assigned stores to build the associated system-access mappings:

AccessDerived from
Department / store accessThe stores listed in Can Sell In.
Transfer FromThe same stores listed in Can Sell In.
Supplier accessThe supplier associated with each assigned Store master.
Transfer ToStores belonging to the applicable supplier(s), together with stores marked as main/warehouse stores.

This is why Store assignments in this screen are more than a reporting label: for cashier-enabled Sales Men/Ladies, they also help IMS configure the operational access required to work from the assigned branches.

The Store master can reference a default Sales Man/Lady for supported transaction workflows.
