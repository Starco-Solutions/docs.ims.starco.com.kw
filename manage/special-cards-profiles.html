Special Cards Profiles

Special Cards Profiles defines the operating rules for IMS Special Cards. A profile controls whether cards expire, whether they are one-time use, how they are redeemed, which Service Item is used for funding, and whether a recharge discount applies.

Open the screenManage → Special Cards Profiles.

Profile settings

SettingPurpose
IDUnique profile identifier. IMS proposes the next available ID when creating a new profile.
NameProfile name shown when a Special Card is created or viewed.
DescriptionOptional description of the profile's intended use.
Is activeMarks the profile as active.
ExpirableEnables automatic expiration for cards created under the profile.
After … Month(s)Number of months after issue before an expirable card expires.
One time useProfile flag for cards intended for one-time-use behavior.
Redeem payment typePayment method used for Special Card redemption. The available list comes from payment methods configured for Star Cards.
Funding ItemcodeService Item used by the card funding/recharge workflow. The … button opens Service Items for selection.
Discount on rechargePercentage discount associated with recharge. IMS accepts values up to 95%.

Create a profile

  1. Click New.
  2. Confirm the proposed ID and enter a profile Name.
  3. Add a Description when useful.
  4. Enable Is active when the profile should be available for use.
  5. If cards should expire, enable Expirable and enter the number of months.
  6. Set One time use when appropriate.
  7. Select the Redeem payment type.
  8. Choose the required Funding Itemcode using the Service Items selector.
  9. Enter any Discount on recharge.
  10. Click Save.
Required setupIMS needs at least one payment method configured for Star Cards before profiles can be created or edited. A Funding Itemcode is also required when saving a profile.

Edit a profile

Select a profile and click Edit. The profile ID remains fixed while the other profile settings can be updated. Click Cancel to discard unsaved changes.

Expiration

When Expirable is enabled, IMS stores an expiration period in months. New cards created with that profile receive an expiration date calculated from the card issue date plus the configured number of months.

How profile settings affect transactions

The funding Service Item and redeem payment type connect this profile to Sales Transactions. A recharge percentage adds that proportion of the net funding amount to the credited value: a hypothetical net funding amount of 100.000 with 10% credits 110.000. It is not a 10% merchandise discount applied whenever the card is spent.

One time use prevents a previously funded, exhausted card from being used on a later sale. Expiration is evaluated against the card's stored expiration date; changing a profile is not an instruction to rewrite every previously issued card's date. See funding, payment and refund handling.
