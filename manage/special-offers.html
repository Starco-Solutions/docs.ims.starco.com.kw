Manage Special Offers

Special Offers is the IMS promotion-rule editor. It defines what benefit the customer receives, when the offer is valid, which stores and client categories can use it, and which merchandise participates. IMS supports percentage discounts, free-item promotions, cash back, fixed-price bundles and step/tiered discounts.

Open the screenManage → Special Offers

How a Special Offer is structured

Every offer starts with the same core information: ID, Name, Start and End. The center section changes according to the selected offer type, while the Apply On area controls Stores, Client Categories and Items.

The five offer types

Offer TypeRuleTypical use
Give DiscountGive a percentage discount to eligible items, or apply the discount on the total invoice amount. It can also use a special price list instead of one percentage.“15% off selected items”, “10% off the invoice”, or item-specific promotional prices.
Give Free ItemBuy N → Get M free items according to the selected merchandise scope.Buy 3 Get 1.
Cash BackDefine one or more purchase thresholds and the cash-back/voucher value to grant. The benefit can be a fixed amount or a percentage.Spend 50 KD → receive 10 KD.
BundleBuy N → For amount, giving a fixed bundle total for the qualifying quantity.Buy 3 selected items for 29 KD.
Step DiscountSupports quantity-based/tiered discounts, including Buy/Get-style tiers, or a List A → List B rule.Buy 2 → 15%; Buy 3 → 20%, or buy items from List A and discount items from List B.

Common offer controls

ControlPurpose
On total invoice amountAvailable for Give Discount. The offer is evaluated on the receipt total rather than on a selected merchandise list; item selection is disabled while this option is active.
On items sold on full price OnlyLimits the promotion to merchandise currently sold at full price.
Override item's discount only if it is less than offerAllows the offer to replace a smaller existing item discount while leaving a better discount unchanged.
Force disable client's special discountPrevents the customer's special/client discount from being combined with this offer.
Apply if receipt's total amount exceededOptional minimum receipt amount required before the offer can apply.
Round Net AmountOptional rounding value stored with the promotion and used by the POS offer-processing logic.

Give Discount

Select Give Discount and enter the discount percentage in the Get … Off field. The rule can target selected merchandise, all items, or the total invoice amount.

If On total invoice amount is enabled, IMS automatically treats the offer as applying to all items and disables merchandise targeting for that policy.

From Price List

A Give Discount offer can use From Price List. In this mode the import file provides an offer-specific selling price instead of one common percentage. IMS stores those promotional prices separately from the Item master.

Selection modeRequired file columns after the header
ItemcodeItem Code · Special Price
StyleStyle · Special Price
Style - ColorStyle · Color · Special Price

When From Price List is selected, All Items, full-price-only and override-discount behavior are disabled because the imported list itself defines the eligible products and their offer prices.

Give Free Item

This is the classic Buy N Get M promotion. Enter the qualifying quantity in Buy and the free quantity in Get, then define where the promotion applies.

ExampleBuy 3 Get 1 means the receipt must contain the qualifying quantity from the offer's eligible merchandise before the free-item benefit is considered.

Bundle

Bundle uses the same qualifying-quantity idea but replaces “Get free” with a fixed total amount: Buy N For amount.

ExampleBuy 3 For 29.000 configures a three-item bundle whose promotional total is 29.000 in the local currency.

Step Discount

Step Discount has two operating styles.

ModeHow it works
Standard List A / List BDiscount a specified number of items from List B when the receipt contains the required number of items from List A. This mode uses Item Code lists.
As buy getBuild a Discounts Policy made of quantity → percentage tiers. For example, Buy 2 → Get 15%, Buy 3 → Get 20%.

For the standard List A/List B version, the import file contains two Item Code columns after the header: List A and List B. IMS validates both lists against the Item master.

For As buy get, the Discounts Policy list can contain multiple quantity/percentage entries. The percentage option is fixed for these tier definitions.

Cash Back

Cash Back is the most specialized mode because it can issue a value for later use or apply the benefit immediately to the current receipt.

Cash Back Criteria

Each criterion pairs a qualifying total with a benefit. The benefit can be a fixed currency value or, when Give percent from Total is selected, a percentage.

Example50.000 → 10.000, 100.000 → 20.000, 150.000 → 30.000. The list is ordered by the qualifying total.

Use Step on every (n) amount when the same criterion should repeat for each qualifying amount step. In this mode IMS keeps one base criterion rather than a multi-threshold table.

Apply on current receipt

Select Apply on current receipt when the Cash Back benefit should be used immediately instead of relying on a later voucher. In this mode the separate Cash Back Terms area is hidden and IMS forces the client's special discount off for the offer.

Voucher expiry and redemption stores

For a normal Cash Back voucher, choose either:

  • Expires on — a fixed expiry date.
  • Expires After — a number of days from the voucher issuing date.

Use in all stores controls where the resulting Cash Back voucher can be redeemed. If it is not selected, use the adjacent … button to choose the redemption stores.

Important distinctionThe Stores list under Apply On controls where the offer can be earned/applied. The Cash Back Use in all stores setting controls where the resulting voucher can be redeemed. These are two different store scopes.

The Cash Back Terms box stores the text printed/associated with the Cash Back policy, such as return or exchange restrictions.

Apply On: Stores, Clients and Items

Every Special Offer has three independent scope areas.

ScopeOptions
StoresSelect specific stores with +/−, or use All Stores. All Stores loads the active retail stores eligible for normal offer application.
Client's CategorySelect one or more customer categories, or use All Clients.
ItemsSelect Style, Style - Color or Itemcode, import a text file, or use All Items.

Item selection and import files

The text-file importer always treats the first row as a header. The normal layouts are:

ModeColumns after the headerResult
ItemcodeItem CodeTargets those exact SKUs.
StyleStyleIMS expands each Style to the Item Codes that currently belong to it.

Multi-offer compatibility: which offers can run together?

When you save a Special Offer, IMS checks whether its Store scope and date range overlap another configured offer. Some offer types cannot be added to a Store/date combination that already has an offer. For the remaining types, the result also depends on the rules of the offer already configured for that Store.

Offer or configurationMulti-offer eligibilityWhat the setup screen permits
Cash Back (voucher or benefit on the current receipt)Not combinableA new Cash Back offer cannot overlap any other offer in the same Store/date range. An existing Cash Back offer also blocks adding another offer there.
Give Discount (item percentage, special price list or invoice-total discount)Cannot be added as a second overlapping offerCreating or editing a Give Discount offer is rejected when another offer already overlaps. A previously configured item-scoped Give Discount can, however, remain when a later eligible item-scoped Free Item, Step Discount or Bundle is added. Do not assume the reverse setup order is accepted.
Invoice Discount / On total invoice amountNot combinableIn addition to the Give Discount restriction above, an already configured invoice-total offer blocks any later overlapping offer.
All Items selected on any Special OfferNot combinableAn offer using All Items cannot be added alongside an overlapping offer, and an existing All Items offer blocks later combinations. Use an explicit eligible-item scope for a potentially combinable offer.
Give Free Item with selected ItemsConditionalMay share a Store/date range with another eligible, item-scoped offer, provided the existing offer is not Cash Back, invoice-total, or All Items.
Step Discount with selected ItemsConditionalSame restriction as Give Free Item, including Step as Buy/Get and List A/List B variants.
Bundle with selected ItemsConditionalSame restriction as Give Free Item; the configured bundle quantity and amount still determine the POS benefit.
Before saving a second offerCheck the Store and Start/End dates of both offers, then check that neither offer uses a disallowed type or All Items scope. Different item lists alone do not override the Cash Back, invoice-total, All Items or new Give Discount restrictions. Setup validation governs whether the offers can coexist; the POS still evaluates each applicable offer's merchandise, customer and transaction eligibility. Cash Back voucher redemption stores are a separate setting from where its offer is earned.

Example: A Store may have an existing item-scoped Buy 1 Get 1 Free Item offer and a separately configured item-scoped Bundle, subject to the normal eligibility checks. If you try to add a new Give Discount or Cash Back during the same dates for that Store, IMS rejects the overlap. Setting All Items on either of the two scoped offers also prevents the combination.

Create or edit an offer

  1. Click New. IMS assigns the next Offer ID and initially selects All Stores, All Clients and All Items.
  2. Enter the Name, Start and End dates.
  3. Select the offer type and configure its values.
  4. Set any optional controls such as full-price-only, client-discount handling, minimum receipt total or rounding.
  5. Choose the Store, Client Category and Item scope.
  6. For Cash Back, complete the criteria, expiry/current-receipt behavior and voucher redemption stores.
  7. Click Save. IMS validates required scopes, dates, offer values and conflicting store offers before saving.

To modify an existing offer, select it, click Edit, make the changes and click Save. Click Cancel to reload the last saved version.

Setting an existing offer's End Date before today is treated as stopping the offer and IMS asks for confirmation.

Delete an offer

An offer can be deleted only while it has never been applied to a sales transaction. IMS checks the transaction history for the Offer ID before allowing deletion.

If the offer has already been used, IMS keeps the definition and displays that the offer cannot be deleted because it has been applied on sales transactions. This protects the historical transaction reference.

Effect on reports

When a Special Offer is applied, the sales transaction retains the Offer ID. Sales reports therefore show the financial result that was actually posted — quantities, full amounts, discounts, net sales and related KPIs — rather than recalculating the promotion definition later.

Permissions

New, Edit and Delete are controlled by the IMS Manage Special Offer access policy. If the user does not have this right, the maintenance actions are disabled.

POS eligibility and calculation reference

The offer must match the working date, store and customer category. Select the correct customer before reviewing the offer result. Item lists are resolved to Item Codes. POS evaluates eligible sale units and shows the resulting prices and discount; a return line is not another purchased unit. Quantity offers count each merchandise unit, even when several units appear on one grid row, and exclude Service Items. Paid and discounted quantities can appear as separate portions of the same Item Code. The optional receipt total exceeded condition is strict when positive: equality with that minimum does not pass; an unset/zero minimum does not impose that threshold.

RuleCalculation and operator check
Item percentage discountUses original price × (1 − discount). Full-price-only excludes already discounted items. Override replaces an existing discount only when the offer percentage is greater. Without either override or full-price eligibility, an existing item discount is retained.
Special price listThe imported price is translated to a discount from original price for that item when Apply Offer is selected. A missing price entry, or a price at/above original price, leaves the current discount. Review the actual line price.
Buy/Get freeEach complete group of Buy N plus Get M eligible merchandise units provides M free units. A partial group earns no additional free unit. Entered quantities count as units (not just distinct grid rows); IMS selects the lowest-priced eligible units for the benefit. A single entered row may be split into paid and free quantities.
Step List A/List BEach complete N qualifying units from List A permits up to M discounted units from List B, subject to eligible B quantity. Repeated units count individually, and benefits are applied to eligible List B units in receipt order.
Step as Buy/GetIn the standard mode, each complete N+M eligible merchandise units permits M discounted units; incomplete groups do not earn an extra benefit. With Get on Any and one percentage, all but one eligible unit can receive that percentage. With a quantity/percentage policy, the highest reached threshold supplies the discount for eligible units.
BundleEach complete group of N eligible units is priced at the configured bundle total; incomplete groups do not earn another bundle. IMS allocates the group discount among eligible units with rounding and a remainder adjustment while preserving the qualifying group total and nonnegative item discounts. Review both individual unit prices and the group total, particularly with different item prices or quantities.
Invoice percentageApplies a second discount to current line amounts, rounded to two decimals per line. It applies when there is no client discount or the offer forces that discount off. Optional rounding sets the final receipt to the configured increment and allocates the difference to a line.
Round Net AmountFor item/step discounts, rounds the resulting price to the nearest multiple of the configured increment and recalculates the effective discount. Midpoint rounding follows nearest-even rounding, not an unconditional upward rounding rule.

Cashback amount and payment exclusions

Cashback uses eligible merchandise value net of return lines. The qualifying base cannot exceed the receipt's merchandise total less voucher payments and Star Rewards redemption. For a threshold list, the highest reached threshold supplies the benefit. For Step on every N amount, whole steps are counted; any remainder does not form another step. A fixed criterion is a currency amount. A percentage criterion becomes that percentage of the qualifying base; in repeating-step mode the percentage criterion is multiplied by the number of whole steps before conversion.

Apply on current receipt distributes the calculated benefit as a receipt discount and does not issue a later-use cashback voucher. In voucher mode, the saved voucher carries its amount, campaign, issue receipt/store and expiry. A later redemption checks existence, unused/uncancelled status, expiry and allowed redemption stores; company settings govern multiple vouchers. The customer receives promotional value, not a Star Card balance or Star Rewards points.

Refunds, size exchanges and retained promotions

Begin with the original sales receipt, not today's Special Offer setup. For a supported receipt, IMS uses the promotion rules, eligible merchandise and saved prices associated with that sale. This applies when several Special Offers contributed to one basket: the returning units are identified against their original receipt rows, and the remaining items are priced as a retained purchase under that original promotion context.

How a partial promotional refund is calculated

  1. Select the exact original units to return; a repeated Item Code may represent more than one separately saved unit.
  2. IMS calculates the value of the remaining basket using the original eligible offers and the quantities that remain. A free-item, step or bundle benefit can move to another eligible unit, or cease to apply when a quantity threshold is no longer met.
  3. Review the signed incremental customer settlement shown in Preview Settlement. It is not necessarily equal to the old printed price of the returned line.
  4. On a supported completed refund, IMS saves linked reversal and, when merchandise remains, a newly priced retained-sale receipt. The original sale and its promotion history remain available for enquiry.
Hypothetical Buy 1 Get 1 exampleThree eligible units cost 10.000, 7.000 and 5.000. Originally the 5.000 unit is free, so the customer paid 17.000. If the customer returns that free unit, the remaining 10.000 and 7.000 units still qualify; the 7.000 unit becomes free. Retained purchase: 10.000; customer refund: 7.000. Refunding the old free line as 0.000 would not represent the revised promotion.

Size exchanges and linked receipts

An eligible size exchange replaces the selected original unit with another eligible size of the same Style, subject to the Store's color-matching and stock rules. IMS retains exact original-unit lineage and produces linked return/replacement documents. A genuine size-exchange replacement is identified as an exchange; the new retained sale following an ordinary partial refund remains a normal sale. A matching-value size exchange can have a zero customer settlement.

Settlement and attention required

The preview separates the internal reversal value from the actual money or approved payment instrument returned to the customer. Earlier refunds and the customer's original instruments are considered. Where voucher, card, note or points history cannot be safely reconciled, follow the displayed restriction or supervisor handling rather than substituting cash.

If recalculation yields a negative incremental settlement, IMS can record the physically received original units as a pending intake. Those units stay reserved and quarantined; no additional customer charge, refund, replacement sale, journal or available-stock release is performed automatically. The case appears in the supervisor review queue for accountable follow-up. A supervisor acknowledgement is not a financial resolution.

For issued cashback vouchers, the original receipt's redemption history remains relevant. An unused eligible voucher may be cancelled as part of an authorized return; an already-used voucher can restrict the permitted operation to size exchange. Future voucher entitlement is not the same as a voucher actually issued. Redemption remains subject to that voucher's original validity and store scope.

Earlier receipts without sufficient verified promotion history can require a manual controlled handling route; IMS does not use today's edited campaign rules as proof of a historical sale. For the cashier procedure, see Promotion refund and exchange. For linked documents and audit, see Transactions Expert.
