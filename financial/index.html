Financial

The Financial area contains IMS accounting integration and financial-control functions. In IMS 9.4.4, Integration Setup also contains the Purchase VAT / Tax Codes configuration when VAT is enabled.

Current production connector IMS is currently integrated directly with the local Al-Shamel Financial Management System. In this manual, Financial Posting is used as the business term, while Al-Shamel is identified as the current production financial connector where the implementation matters.
