IMS API

Central service layer used by IMS for secure bootstrap, Global administration and the read-only External Business API v1 through route-separated security boundaries.

Current responsibilities

IMS.Api is the trusted service boundary used by the client/administration applications for workstation checks, global authentication, company authorization/routing, Global Administrator sessions, company/user/workstation administration, system version management and protected secret access.

Global administration

Administrator setup belongs in the IMS Global API Administration guide; external clients use the Business API guide below.

IMS Global does not write global administration data by opening ims_global directly. Its Companies, Users, Workstations and System Version operations are mediated through authenticated Global Admin API calls. Database runtime/provisioning information is also requested through that authorized service boundary.

Business API v1

/api/v1 is the route contract version; IMS API 1.1.0.0 is the application release version. Verify availability for the intended installation with its administrator.

The External Business API v1 is a read-only contract separate from Bootstrap and Global administration. External clients authenticate with X-IMS-API-Key, are restricted by assigned companies, scopes and company contract policies and read approved business data through /api/v1/companies/{companyId}/... routes.

The business contract covers stores, items, suppliers, the read-only Customers Catalog and Customer Delta, hourly Footfall, sales, purchases, inventory/balances/movements, transfers, adjustments/depreciation, markdowns, promotions and discount-coupon event metadata. The standalone reference covers 22 ordinary GET operations and two separately policy-controlled Partner Data GET operations. External clients do not receive direct PostgreSQL access.

Developer documentationSee the Business API v1 Developer Guide for quick-start calls, authentication, complete endpoint reference, business semantics, errors/rate limits and downloadable request collections.

Partner Data and service consumers

Partner Data provides policy-controlled catalog and Stock Delta endpoints under the independent partner-data.read scope. Internal Autos interfaces separately support unattended authentication, authorized-company bootstrap and workload-scoped credentials for compatible consumers. API-side capability does not automatically upgrade or activate a worker; see worker compatibility.

Separation mattersDo not treat Global administration endpoints as the public/business integration API. They exist to operate the IMS platform securely.
