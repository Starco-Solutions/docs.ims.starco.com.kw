IMS Architecture

System-level view of the IMS Windows client, IMS.Api, IMS Global, separate company databases and server-side integration workers.

Core components

ComponentRole
IMS clientWindows operational application used for POS, inventory, purchasing, finance, reporting and administration inside the selected company.
IMS.ApiCentral service boundary for secure bootstrap, authentication, workstation checks, company routing information, Global administration and protected secrets.
IMS GlobalDedicated administration application for company records/database profiles, Global users/company access, workstations, version control and controlled cross-company setup tools.
ims_globalGlobal identity, company/access, workstation, version, API administration and protected-secret data.
Company databasesIndependent PostgreSQL databases containing each company's operational configuration, stores, inventory, transactions, finance and history.
Background/integration workersIMS Autos is a Windows service; the Shopify integration worker is a running Windows desktop application. Their operating lifecycle and credential consumption must be verified separately.

Session flow

  1. The workstation is validated.
  2. The user authenticates against the global IMS identity.
  3. IMS resolves active company access.
  4. The default/selected company determines the company database runtime profile.
  5. The client opens the company operational context and then applies company-local permissions.
Separation by designGlobal identity and company membership are centralized, while operational data and local authorization remain company-specific.

Runtime and version boundaries

The authorized IMS client receives a company runtime profile and connects directly to PostgreSQL; the API does not proxy all operational SQL. Secret storage at rest, API authorization and client runtime exposure are separate boundaries. The installed worker must support the configured credential storage path. API-side authentication and vault capabilities do not automatically upgrade Autos or Shopify consumers. Confirm component compatibility before onboarding or rotation; a stored-secret indicator is not a successful connection test.

See component versions and compatibility.
