Secure Bootstrap

The protected startup sequence that validates the IMS workstation, authenticates the global user and establishes authorized company context.

Bootstrap sequence

  1. IMS identifies the workstation and sends the workstation identity/fingerprint and client version to IMS.Api.
  2. IMS.Api confirms whether the workstation is authorized.
  3. The user's global Login Name and password are authenticated.
  4. If a password change is required, the user completes it before continuing.
  5. The API returns only the active companies authorized for that identity, including default-company information.
  6. The chosen company is validated and its runtime database profile is supplied for the authorized session.
  7. The IMS client opens the selected company's operational database and applies that company's local permissions.
IMS Global uses the same security boundaryThe administration application first passes workstation validation and user authentication, then opens a separate Global Administrator session through IMS.Api.
