IMS Security Guard & Sign-in

The supported startup experience checks workstation approval, user identity, application version and company access before opening the IMS Client or IMS Global administration tools.

Sign-in sequence

  1. Open IMS Client or IMS Global on a registered workstation.
  2. If IMS reports that the workstation is pending or blocked, contact a Global Administrator for review in IMS Global → System → Workstations.
  3. Sign in with an authorized IMS account. Complete any required password-change prompt.
  4. Choose an available company when the application requests company selection.
  5. IMS opens the permitted features based on the user's company-local policies. Global administration requires the separate Global Administrator permission.

Application versions and supported interfaces

An unsupported client or administration version must be updated through the approved IMS update process before login can continue. IMS Client and IMS Global have independent version requirements; check the application's displayed version and the release information maintained by the administrator.

The IMS sign-in process is an internal product function, not an external integration interface. Integration developers must use the documented Business API v1 endpoints and the appropriate approved API scopes.

Resolve sign-in problems

  • Workstation not authorized: ask an authorized administrator to check the registered device and approve or block it through the Workstations screen.
  • Password update required: follow the application prompt, then sign in again.
  • Company unavailable: verify the active company assignment and company access with the administrator.
  • Application update required: install the compatible approved release before retrying.
  • Connection unavailable: verify the IMS API address, network connectivity and server health using IT troubleshooting.

Initial administrator workstation authorization for a new installation uses the approved initial-setup procedure; routine workstation changes use IMS Global. Do not attempt direct database modifications as an authorization procedure.
