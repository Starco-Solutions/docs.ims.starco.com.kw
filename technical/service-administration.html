Autos and Shopify service administration

Install, authorize and maintain IMS Autos 9.2 and Shopify Integration Server 4.4.0 with IMS Global and the supported Recovery Package installer. Each service has independent company access and business responsibilities.

What each service does

ComponentPurposeAdministration
IMS AutosScheduled jobs, reports, integrations, stock recalculation and authorized receipt delivery.IMS Global controls company authorization. IMS Client → Tools → IMS Autos controls company schedules and logs.
Shopify Integration ServerShopify orders, fulfillment preparation and inventory synchronization for configured profiles and stores.IMS Global controls company authorization; Shopify Manage Profiles controls store/profile setup and execution.

Authorize companies and services

  1. Open IMS Global → Services as an authorized administrator.
  2. Select the company and choose Autos or Shopify.
  3. Review the assigned service identity, company grant and active state. Approve the intended company access.
  4. For Autos, enable the company when its scheduled work may run. For Shopify, configure the company's profiles, active stores and Store access in the Shopify application.
  5. Verify access and business results in each application's logs before considering the setup complete.

Service access is separate from employee logins and from external Business API client keys. Never put passwords or API tokens into screenshots, support attachments or ordinary documentation examples.

Installation prerequisites

  • Use a supported Windows host and install the .NET 10 Windows Desktop Runtime x64 when required by the installer.
  • Confirm reliable connectivity to the authorized IMS API HTTPS address and the databases needed by enabled companies.
  • Verify the host's approved network and certificate configuration with its administrator. Transport-security choices are installation-specific, not defaults to copy from another company.
  • Confirm the intended Windows user will operate the Shopify desktop application and can approve the supported installation prompts.

Install or replace Autos and Shopify

  1. In IMS Global → Services, review the intended Autos and Shopify identities and their company grants.
  2. If replacing a running Services host, stop or disable the old host through the approved maintenance process. Allow active work to finish so that old and new hosts do not run the same jobs concurrently.
  3. Choose Generate Recovery Package. Review the intended service selection and API destination shown by IMS Global, then confirm.
  4. Transfer the generated installer securely to the intended Windows host. Run it as the authorized Shopify desktop user and approve the Windows administrator prompt.
  5. Complete the installer's displayed prerequisite and installation steps. If it rejects an expired package, generate a fresh package in IMS Global.
  6. Verify that Autos is installed and running. Open Shopify using its installed shortcut and confirm the expected company profiles and Store settings.
  7. Enable the authorized company schedules, check Autos jobs and receipt/integration outcomes, and verify Shopify orders and inventory tasks as applicable.
  8. Retire the old host only after both services are verified and the responsible administrator approves the handover.
Recovery Package is not a database backupThe IMS Services installer installs and authorizes Autos and Shopify. Database backup restoration and IMS Server Disaster Recovery are separate procedures described in IMS Server Deployment.

Receipt delivery dependencies and monitoring

Receipt generation requires a supported Windows environment and Microsoft Edge. Configure the company's email or WhatsApp channel through the relevant IMS administration screen. The cashier workflow must have a valid recipient and required consent before delivery is attempted.

Use IMS Autos receipt status and logs to check outcomes. A provider accepting a message is not proof it reached the recipient. For uncertain delivery, investigate the existing request before an approved resend to prevent duplicate receipts.

Operational checks and troubleshooting

  • Service does not start: check the installed runtime, Windows service state and Event Log, then retry the supported installer or maintenance action.
  • Company missing: check IMS Global service grants and company active/Autos Enabled status. Restart Shopify to refresh its available companies when needed.
  • Jobs not running: verify company schedules, time zone, required configuration and Autos job logs.
  • Shopify not synchronizing: verify selected profile, store assignments, active state, Shopify authorization and the application log.
  • Authorization or connection error: validate the approved IMS API address, certificate trust, network access and permissions with the administrator. Never bypass normal enrollment by copying credentials from another machine.

Developer Access

Authorized technical users can request Developer Access through IMS Global → Users. This is separate from Autos service administration and does not authorize replacing service credentials.
