Credential Administration

Manage IMS database and integration credentials through authorized application screens without displaying or sharing existing secret values.

Purpose

IMS provides protected credential administration for supported database connections and integrations. The user-facing screen shows whether a credential is configured, but an existing password is not displayed back to the operator.

Company database passwords

  1. Open IMS Global → Companies as an authorized administrator.
  2. Select the intended company and review its database profile.
  3. When changing a credential, enter the new value in the authorized prompt, confirm the target and save.
  4. Verify the affected company connection before returning dependent services to operation. Leave a saved password blank only where the UI explicitly states that the current value will be retained.

Operational rule

Protect account accessDo not place passwords, recovery material or tokens into scripts, screenshots, log attachments, reports or the public guide. Protect backup and recovery material under your organization's approved administrator procedures.

Credential replacement

For a supported service or integration, select the intended company and configuration screen, update the relevant credential using the UI and perform an authorized connection or job check. Coordinate credential changes with the responsible service administrator.

Component compatibility

Autos and Shopify use separate service authorization and company grants. Install or replace those applications through IMS Global → Generate Recovery Package. For a complete server recovery, use IMS Server Deployment.
