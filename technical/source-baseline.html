Component Versions and Compatibility

Documentation versions, supported interfaces and deployment prerequisites for the IMS product family.

ComponentDocumented versionInterfaces and compatibility
IMS Client9.4.5 — live releaseWindows/.NET Framework 4.8, company PostgreSQL access and authorized API bootstrap. IMS Client 9.4.5 is the current production release and the baseline for this guide.
IMS Global1.5.0.0Global administration through IMS API; new-company provisioning includes the 24-view Business API, Partner Data and Delta contracts.
IMS API1.0.0.0Business API v1, Partner Data, client bootstrap and separate administrative/internal-service interfaces.
IMS Autos9.1.2Windows service on .NET Framework 4.8; scheduling and integration processing require worker-compatible company connection and credential configuration.
Shopify Integration Server4.2.0Windows desktop worker on .NET 10; requires supported Shopify profile and credential configuration and a running application session.

IMS Client 9.4.5 functionality and bug fixes

  • Client's Info: optional Gender/Nationality, editable Loyalty profiles, Save/Cancel behavior and ERP-linked read-only profiles. Also used by the authorized historical-client editing workflow.
  • Stock Adjustments bug fix: repaired missing item_prods balance-row insertion in existing new/edit voucher workflows; no new inventory capability was introduced.
  • New-store creation: transactional initialization of missing document counters while preserving existing values.

IMS Client 9.4.5 is live. Individual workstations must still complete their update before release-specific functionality is available locally.

Planning an installation or upgrade

IMS Client 9.4.5 is the current production release. The other component versions below describe documented interfaces, not a guarantee that all endpoints or workers are upgraded. Verify the installed combination with your administrator; an API upgrade does not upgrade or reconfigure background workers.

Company database contracts

New companies created in IMS Global 1.5.0.0 receive the current API contracts. Existing company databases require the applicable approved migrations and access validation; updating IMS Global alone does not migrate them. Partner Stock Delta activation also requires company-level migration and operational acceptance for the intended catalog size.

Worker credential compatibility

IMS Autos 9.1.2 and Shopify Integration Server 4.2.0 use their existing worker credential configuration. API-side workload authentication and vault access are separate capabilities. Before changing a credential storage path or rotating credentials, confirm that the installed consumer supports that path and verify a controlled connection.

See Business API v1, IMS Global administration, IMS Autos and Shopify Integration Server.
