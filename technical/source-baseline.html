Component Versions and Compatibility

Documentation versions, supported interfaces and deployment prerequisites for the IMS product family.

ComponentDocumented versionInterfaces and compatibility
IMS Client9.4.6.0Windows/.NET Framework 4.8, company PostgreSQL access and authorized API bootstrap. IMS Client Build 9.4.6.0 is the current production release and the baseline for this guide.
IMS Global1.7.0.0Global administration through IMS API; new-company provisioning includes the 28-view Business API, including Customers Catalog, Partner Data and Delta contracts.
IMS API1.1.0.0Business API v1, Customers Catalog, Customer Delta, Footfall, Partner Data, client bootstrap and separate administrative/internal-service interfaces.
IMS Autos9.2Windows service on .NET 10; separate company time zones, API service bootstrap and authorized company scheduling.
Shopify Integration Server4.4.0Windows desktop worker on .NET 10; independent company/profile workers, API bootstrap and per-store Shopify App Tokens; requires a running application session.

Client workflows

IMS Client 9.4.6 includes employee sales, digital and printed receipts, inventory, finance, reporting, merchandise management, permissions and system monitoring. Use the module guides for the controls available to your company and user.

Component compatibility

These are the current documented product versions. Install the correct application version and applicable company database contracts together. An API upgrade does not install or configure desktop applications or background services. IMS Global and Client have distinct version gates and authentication sessions.

Company database contracts

New companies created in IMS Global 1.7.0 receive 28 API contract views and the required catalog/delta support through the consolidated IMS_DB_Create.sql provisioning script. Existing company databases require the applicable approved migrations and access validation; updating Global alone does not migrate them. Scope registration, client authorization and per-company contracts are separate. See API administration.

Worker authorization

Autos 9.2 and Shopify 4.4.0 use secure IMS API bootstrap and separate service identities and company grants. Autos runs as a Windows service and schedules companies in their own time zones; Shopify runs independent company/profile workers in its desktop application. Protected host credentials, authorized company access and company/profile settings must all be available. See service administration.
