IMS API 1.0.0.0 • Business API v1

Business API v1

Read-only external API for approved IMS business data across authorized companies. It is designed for integrations, analytics and data consumers that need a versioned HTTPS interface without direct database access.

Start hereIf you received an API key and company ID, open Quick Start. It contains copy/paste calls and the minimum information required to make a successful request.

What the API exposes

Master data

Stores, Items & Suppliers

Store/warehouse attributes, merchandise master data and supplier identity used by business transactions.

Transactions

Sales & Purchases

Sales/returns, COGS, salesperson/customer references, purchases/returns, local and landed cost.

Inventory

Balances & Movements

On-hand stock, stock value, movement history, transfers, adjustments and depreciation.

Commercial

Markdowns & Promotions

Markdown policies, promotion definitions/relations and discount-coupon event metadata.

Security model

Every business request is authenticated with the X-IMS-API-Key header. Access is limited by the client record, assigned companies and assigned scopes. API keys can be expired, rotated or revoked by an IMS Global administrator.

Versioning

This guide documents IMS API 1.0.0.0 and the /api/v1 contract with IMS Global 1.5.0.0 company provisioning. Confirm the installed component versions and required company migrations before enabling a new interface. See Component Versions and Compatibility.

Business API versus internal client APIs

The 19 ordinary operations in the endpoint reference and two Partner Data operations are read-only GET operations under /api/v1/companies. Bootstrap, Global administration, internal service authentication and protected-secret operations use separate authorization. Ordinary Business API keys do not grant those permissions.
