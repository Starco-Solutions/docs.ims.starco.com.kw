Quick Start

Make a successful IMS Business API request in a few minutes using the base URL, company ID and API key issued to your integration.

1. Required values

ValueExampleNotes
Base URLhttps://api.example.comUse the HTTPS base URL supplied for the IMS environment.
Company ID1The company must be assigned to your API client.
API keyims_live_...Send it in X-IMS-API-Key. Treat it as a secret.

The Stores and Sales examples need stores.read and sales.read respectively. For a partner-only key, start with the Partner Data handshake.

2. First request: Stores

curl "https://api.example.com/api/v1/companies/1/stores"   -H "X-IMS-API-Key: YOUR_API_KEY"   -H "Accept: application/json"

A successful response returns HTTP 200 with company metadata, a count and the store/warehouse data array.

3. Date-based request: Sales

curl "https://api.example.com/api/v1/companies/1/sales?fromDate=2026-09-01&toDate=2026-09-30&page=1&pageSize=100"   -H "X-IMS-API-Key: YOUR_API_KEY"   -H "Accept: application/json"

4. Typical paged response

{
  "companyId": 1,
  "companyCode": "COMPANY",
  "companyName": "Company Name",
  "page": 1,
  "pageSize": 100,
  "count": 0,
  "totalCount": 0,
  "totalPages": 0,
  "data": []
}
Next stepSee Endpoint Reference for available resources and filters, and Data Semantics before aggregating financial/inventory values.

Customer catalog

For an approved customer export, use customers.read and follow the Customers examples. Read all pages of the full catalog. To maintain a customer mirror, first capture the Customer Delta baseline and revision, then export the catalog and apply subsequent changes.

Ready-to-run request file

Download IMS_API_v1.http for Visual Studio/VS Code HTTP Client examples covering every API v1 endpoint. Replace the three variables at the top and run the requests directly.

Choose the right synchronization resource

The reference contains all 24 operations. Use ordinary resources only with approved scopes and a configured company contract. For hourly traffic, request /footfall?fromDate=2026-10-01&toDate=2026-10-01 with footfall.read. For partner catalog/availability integration, use the distinct Partner Data policy and synchronization sequence.

Set your authorized host, company and key locally in the HTTP or Postman downloads. Run the initial Delta handshake before any full export; synthetic timestamps and revision values are illustrative, never a substitute for returned cursors.
