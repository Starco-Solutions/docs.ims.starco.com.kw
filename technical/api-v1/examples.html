Examples & Downloads

Practical examples for common clients plus complete request collections for Business API v1.

curl

curl "https://api.example.com/api/v1/companies/1/inventory?nonZeroOnly=true&page=1&pageSize=200"   -H "X-IMS-API-Key: YOUR_API_KEY"   -H "Accept: application/json"

PowerShell

$headers = @{ "X-IMS-API-Key" = "YOUR_API_KEY" }
$uri = "https://api.example.com/api/v1/companies/1/sales?fromDate=2026-09-01&toDate=2026-09-30&page=1&pageSize=200"
$response = Invoke-RestMethod -Method Get -Uri $uri -Headers $headers

C# HttpClient

using var http = new HttpClient();
http.BaseAddress = new Uri("https://api.example.com/");
http.DefaultRequestHeaders.Add("X-IMS-API-Key", "YOUR_API_KEY");

var response = await http.GetAsync(
    "api/v1/companies/1/sales?fromDate=2026-09-01&toDate=2026-09-30&page=1&pageSize=200");

response.EnsureSuccessStatusCode();
string json = await response.Content.ReadAsStringAsync();

Customers: monthly full-catalog export

These examples use synthetic placeholders and fictional response values. Replace the host, company ID and API key with approved values. The key needs customers.read. The monthly schedule belongs to your integration. Retrieve every page for a full export. For incremental synchronization, follow Customer Delta; the full-catalog route has no date filters or push delivery.

curl

curl "https://api.example.com/api/v1/companies/1/customers?page=1&pageSize=200" \
  -H "X-IMS-API-Key: YOUR_API_KEY" \
  -H "Accept: application/json"

PowerShell: collect all pages before reconciliation

$baseUrl = "https://api.example.com"
$companyId = 1
$headers = @{ "X-IMS-API-Key" = "YOUR_API_KEY"; "Accept" = "application/json" }
$page = 1
$customers = [System.Collections.Generic.List[object]]::new()
do {
    $uri = "$baseUrl/api/v1/companies/$companyId/customers?page=$page&pageSize=200"
    $response = Invoke-RestMethod -Method Get -Uri $uri -Headers $headers -ErrorAction Stop
    foreach ($customer in $response.data) { $customers.Add($customer) }
    $page++
} while ($page -le $response.totalPages)
# Reconcile only after the entire download succeeds.
# Each request has its own snapshot; this is not an export-wide snapshot.
# Do not log or publish customer payloads or API keys.

HTTP request

GET /api/v1/companies/1/customers?page=1&pageSize=200 HTTP/1.1
Host: api.example.com
X-IMS-API-Key: YOUR_API_KEY
Accept: application/json
