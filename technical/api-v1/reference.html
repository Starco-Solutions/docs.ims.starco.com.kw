Common paging parameters

All endpoints marked Paged support page and pageSize in addition to the filters below. Default page size is 200; maximum is 1000.

Movement and promotion type text is trimmed and normalized to uppercase. Relationship promotionId and couponEventId must be positive. Promotion relationship handlers do not perform a parent-existence lookup; empty related data is not proof that the promotion does not exist.

Selected field types

This is a partial DTO reference, not a complete schema. Sales invoiceNo is a 64-bit integer; storeId, transactionType, lineNo and itemType are nonnullable integers. customerId, loyaltyCustomerId and salespersonId are nullable integers. quantity, netQuantity, grossSalesAmount, netSalesAmount and cogsAmount are nullable decimals. Preserve integer precision when consuming document numbers. Fixed decimal scale and timestamp timezone semantics require a separately verified contract.

Supplier search performs case-insensitive name/Arabic-name pattern matching. Supplied filters narrow results together. See Requests & Responses for envelopes/date boundaries and Data Semantics for the unresolved view-calculation boundary.
