Business API endpoint reference

All 24 GET operations: 22 ordinary business resources and two separately authorized Partner Data operations.

Examples are synthetic. Replace the host, key and identifiers with approved test values. All operations require one X-IMS-API-Key header, active client/key and company assignment. Company IDs are integers from 1 to 32767. Ordinary external clients additionally need a configured company contract. A scope alone does not grant unrestricted data. Contract policies explain row visibility and the trusted-internal exception.

Every response field listed below is present; nullable fields use JSON null. Numbers are JSON numbers, not strings. Preserve int64 precision. Optional omitted filters impose no additional filter unless stated. Boolean query values are true or false; strings use exact matches after trimming except supplier search. This read-only API does not create or change transactions.

Required scope: promotions.read. Company and policy: The event must qualify for the contract; returned store rows must also be authorized.
